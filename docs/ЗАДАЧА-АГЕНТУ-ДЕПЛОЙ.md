## 1. Что изменилось

**Название и логотип**
- Сайт переименован в `ПРОЕКТЪ ЖЕЛѢЗО` (буква Ѣ — U+0462, не заменять на Е). Название в шапке, подвале,
  на экране загрузки, в заголовках вкладок, копирайте и правовых текстах.
- Логотип сайта — буква π, шестерня убрана.
- Экран загрузки: колесо → название в две строки → счётчик, всё по центру экрана.
- В подвале появился знак студии-разработчика (монограмма CP): цвет наследуется от строки подписи,
  акцент перекрашен в песочный цвет сайта. Встроен в разметку, отдельного файла нет.

**География и СЕО**
- Сайт нацелен на Республику Хакасия. Слова «в Абакане» в видимых текстах нет — только «в Хакасии».
  Город остался в невидимой разметке зоны обслуживания (список из 9 городов) — так и задумано.
- У каждой страницы свой заголовок для поисковика (`seoTitle`) и описание.
- На главной — разметка `ProfessionalService` (schema.org).
- Канонические адреса, Open Graph, гео-метки.
- `robots.txt` и `sitemap.xml` генерируются сборкой.

**Каталог**
- Позиция может относиться к нескольким разделам: в `content.json` вместо `cat` теперь `cats: []`, фильтр ищет по любому.
- Добавлен раздел `taxonomy` — правила, по которым админка угадывает раздел загруженного фото по имени файла.
- Направлений работ теперь четыре: Металлоконструкции, Отопление и тёплый пол, Водоснабжение, Мебель.

**Админка**
- Русские имена файлов транслитерируются при загрузке (`кровать.jpg` → `krovat.jpg`).
- После загрузки фото предлагается создать позицию каталога в угаданном разделе.
- Разрешена загрузка в `assets/img`.
- На проде без `GITHUB_TOKEN`/`GITHUB_REPO` сохранение отдаёт понятную ошибку вместо тихой потери правок.

**Блок «Создай своё»**
- Промпт переписан: раньше постоянная шапка съедала 1245 символов из лимита 2048 и описание изделия
  обрезалось на полуслове — отсюда были «непонятные фигуры» вместо заказанного объекта.
- Добавлены кнопки «Создать заново» и «Удалить».

**Калькулятор: новый раздел «Рассчитать с ИИ»**
- Новые файлы: `api/calc-ai.js`, `assets/js/calc-ai.js`.
- Модель `@cf/meta/llama-3.3-70b-instruct-fp8-fast` со строгой схемой ответа (JSON mode).
- Промпт собран из норм мастерской, климата Хакасии и реальных коэффициентов расхода из `calc-formulas.js`.
- В ответе есть блок «Советы мастера». Кнопки: Telegram, копировать, почта, сохранить файлом, распечатать, удалить.
- В `vercel.json` добавлен блок `functions` с `includeFiles: content.json` — **не удаляй его**:
  без него функция на проде не увидит список норм.

**Правки по коду**
- Исправлено растяжение фотографий (`img { height: auto }`).
- Курсор получил состояния `-fusion` и `-fusion-big` (режим разницы цветов), как в эталонном сайте.
- В `calc.css` заменена несуществующая переменная `--line` на цвет рамок сайта — из-за неё молча не рисовались границы блоков.
- В серверных функциях сначала проверяется ввод пользователя, потом наличие ключей.
- В админке заголовок раздела переведён с `h1` на `h2` — на странице должен быть один `h1`.

## 2. Что сделать

1. Забрать изменения из рабочей папки, проверить сборку:
   ```bash
   node build.js
   ```
   Ожидаемо: 10 страниц + `sitemap.xml` + `robots.txt`, без ошибок.

2. Закоммитить одним коммитом и запушить:
   ```
   rename to ПРОЕКТЪ ЖЕЛѢЗО, Khakassia SEO, multi-category catalog,
   photo auto-placement, AI material calculator, image-prompt budget fix
   ```

3. Проставить в Vercel → Settings → Environment Variables (Production и Preview):

   | Переменная | Значение |
   | --- | --- |
   | `ADMIN_PASSWORD` | длинный пароль, передать владельцу |
   | `GITHUB_TOKEN` | fine-grained, Contents: Read and write на этот репозиторий |
   | `GITHUB_REPO` | `toneplaceconnect-afk/project-p` |
   | `GITHUB_BRANCH` | `main` |
   | `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN` | уже стоят, проверить |

4. Задеплоить и подключить автодеплой из GitHub (Vercel GitHub App).
