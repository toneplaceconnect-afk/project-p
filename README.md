# Сайт «ПРОЕКТЪ ЖЕЛѢЗО»

Обычный статический сайт: 10 готовых HTML-страниц, которые собираются из одного файла с контентом.
Никаких баз данных и фреймворков — только Node.js для сборки.

## Из чего состоит проект

| Файл или папка | Что это |
| --- | --- |
| `content.json` | **Весь текст, списки, ссылки и пути к фото.** Это то, что правит админка. |
| `build.js` | Сборщик: читает `content.json` и создаёт из него все HTML-страницы. |
| `*.html` | Готовые страницы. Их **не нужно править руками** — они перезаписываются сборкой. |
| `admin.html`, `assets/admin/` | Админка: страница входа и редактор контента. |
| `api/admin.js` | Серверная часть админки: вход, сохранение контента, загрузка фото и видео. |
| `api/generate-sketch.js` | Блок «Создай своё»: запрос к Cloudflare для генерации визуализации. |
| `assets/photo/`, `assets/video/` | Фотографии и видео сайта. |
| `assets/css/`, `assets/js/`, `assets/fonts/`, `assets/vendor/` | Стили, скрипты, шрифты и библиотеки — всё своё, без внешних CDN. |
| `serve.js` | Локальный сервер для проверки сайта на компьютере. |

Правило простое: **меняется `content.json` → запускается `build.js` → страницы обновляются.**
Админка делает оба шага сама.

## Переменные окружения

Локально — файл `.env` (создаётся копированием `.env.example`), на Vercel — раздел
**Settings → Environment Variables**. Ключи нигде в коде не хранятся.

| Переменная | Зачем | Где нужна |
| --- | --- | --- |
| `ADMIN_PASSWORD` | Пароль входа в админку | везде |
| `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN` | Генерация картинок в блоке «Создай своё» | везде |
| `GITHUB_TOKEN` | Токен GitHub с правом записи в репозиторий сайта | только на Vercel |
| `GITHUB_REPO` | Репозиторий в виде `логин/название` | только на Vercel |
| `GITHUB_BRANCH` | Ветка, по умолчанию `main` | только на Vercel |

## Как запустить на компьютере

```bash
node serve.js
```

Сайт — на `http://localhost:5178`, админка — на `http://localhost:5178/admin.html`.
В этом режиме админка пишет прямо в файлы проекта и сразу пересобирает страницы:
достаточно обновить вкладку сайта.

Пересобрать страницы вручную:

```bash
node build.js
```

## Как это работает на Vercel

1. Репозиторий подключается к Vercel, команда сборки уже прописана в `vercel.json` (`node build.js`).
2. Админка открывается по адресу `ваш-домен/admin.html`, вход — по `ADMIN_PASSWORD`.
3. При нажатии «Сохранить» админка коммитит `content.json` (а при загрузке фото — и файлы)
   в репозиторий через GitHub. Vercel видит коммит и пересобирает сайт — правки появляются
   на сайте через 1–2 минуты.
4. Страница админки закрыта от поисковиков (`noindex`), но доступна по прямой ссылке —
   поэтому пароль должен быть длинным.

## Что можно менять в админке

- **Контакты и название** — телефон, почта, Telegram, надписи в шапке, меню и подвале.
- **Видео и фото шапки** — видео главной, заставка к нему и подписи (alt) ко всем фотографиям.
- **Меню сайта**, **выпадающее меню «Каталог»**.
- **Каталог работ** — категории фильтра и карточки работ: добавить, удалить, переставить, сменить фото.
- **Блоки** «Варианты изделий», «Направления работ», «Создай своё», лента фотографий, процесс работы.
- **Страницы** — заголовки, тексты, списки, фото, цены, нормы, правовые тексты.

В длинных текстах можно использовать подстановки — они заменятся на актуальные контакты:

- `{phone}` — телефон ссылкой,
- `{email}` — почта ссылкой,
- `{telegram}` — ник в Telegram ссылкой,
- `{brand}` — название сайта.

Выделение жирным внутри текста — тегом `<strong>слово</strong>`, перенос строки — `<br>`.

## Загрузка фото и видео

Кнопка «Выбрать файл» у любого поля с картинкой открывает библиотеку файлов: там можно
выбрать существующий файл, загрузить новый (jpg, png, webp, svg, mp4 — до 12 МБ) или удалить ненужный.
Все файлы складываются в `assets/photo` и `assets/video`, другие папки закрыты.

Видео шапки лучше заранее сжимать: браузер грузит его целиком, комфортный размер — до 8–10 МБ.
